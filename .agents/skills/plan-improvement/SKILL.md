# Plan Improvement Skill

Use this skill when the task is unclear, large, or needs a structured execution
plan before implementation.

## When To Use

- The request spans multiple files, modules, or phases.
- The scope is unclear and needs decomposition.
- You need a milestone-based roadmap.
- You need to compare options by impact, effort, and risk.
- You need a clean handoff plan for implementation work.

## Planning Workflow

1. Define the problem in one sentence.
2. State the desired end state.
3. Split the work into phases or milestones.
4. List dependencies, risks, and assumptions.
5. Prioritize the next concrete action.

## Plan Format

- Current state
- Target state
- Constraints
- Proposed phases
- Validation steps
- Open questions

## Output Standard

Keep plans concrete and executable. Prefer short action items over abstract
goals, and include success criteria for each phase when possible.
